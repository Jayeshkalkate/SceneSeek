# Reference collection

Add per-title folders here. Each must include `metadata.json` and a `frames/` directory containing only frames you are allowed to use. `tools/index_reference.py` builds `index.json` from this folder.

No copyrighted movie/anime clips or posters are bundled by SceneSeek. Keep a source URL, license/basis, attribution, and any restrictions for every title's frames. For public-domain materials, independently confirm the jurisdiction and specific file's rights before use.
